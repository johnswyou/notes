The following prompt is useful when you have gone through an agent session of correcting raw transcripts that were produced using a transcription service such as TurboScribe or fireflies.ai and want to start a new agent session to produce a synthesis of the corrected transcriptions. The workflow that I use is described in: https://www.jy-blog.com/blog/4-knowledge-accumulation-from-meetings/

> Next, produce a handoff doc containing **much** of the key information you learned here so that the next agent session doesn't have to spend time rediscovering **hard-to-find** facts. That session will be responsible for synthesizing insights from the corrected transcripts into **well-structured** synthesis docs, so keep that in mind when preparing the summary. Save the document in a temporary location where the next agent session can easily access it.
